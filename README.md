                  The MAZE Game by Jared Small and Owen Blanc

The project's idea is a game in which there are two turtles within the maze. One turtle is used as the finish line while the other is moving towards it. The green turtle can be moved with the arrow keys, and the other turtle is stationary. Each position is randomly generated from a set of four coordinates within the maze. The walls of the maze are generated using different coordinates imputed into the code. When the turtle is moving around the maze and meets one of the walls, the turtle is moved back to the starting position. 

Owen designed parts of the project, including creating different turtles, adding keys to their corresponding movements, and creating different setpoints for each turtle's location. 
The part of the project that Jared designed was the coordinates for all the walls, the code to draw the walls, and the game loop definition, which allows the game to run. Also, implemented the speed of each of the movements and part of the collision code for the walls.

The way to run the code is to hit the play button within Thonny. Once pressed, the game starts. The green turtle will be able to move throughout the maze, and once it meets the other turtle, a prompt within Thonny will appear as “You Win”. The different modules that were implemented into the code are the turtle module, time module and random module.  

The project difficulty on a scale of 1-10 would be a 7, where finding new ways to implement the wall feature was hard. It was difficult to determine how to make the game restart or stop if the turtle hit one of the walls. Once that was found out, the other aspects of the game were less difficult. The other complicated part of the code was getting the arrow keys to move the turtle. The issue was a simple indentation error that took a while to figure out.
